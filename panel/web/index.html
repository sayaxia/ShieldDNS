上游 DNS

本机 DNS 在「开启防护 / 接管」之前读取一次并写入上游；之后即使网卡 DNS 被改成 127.0.0.1 也不影响。回环地址与自身监听地址会被自动剔除，读不到时回退到上面保存的自定义上游。

接管会记录每块网卡原有的 DNS，再统一改为 127.0.0.1；还原时逐项恢复。需要管理员权限，且核心必须监听 53 端口——装了下面的「后台助手」之后，普通权限也能接管/还原，不再弹 UAC。

后台助手（免 UAC 接管）

未安装

安装一次之后，面板就能以普通权限完成「切 53 端口 + 接管系统 DNS / 还原」，不再每次弹 UAC。助手是一个 SYSTEM 身份的开机计划任务，常驻在命名管道 \\.\pipe\ShieldDNS-DNS-Helper 上，只接受当前用户、且只响应接管/还原/查询三件事。安装这一步需要管理员权限（会弹一次 UAC），之后一直免弹。

异常还原保护（看门狗）

未注册

注册一个计划任务（SYSTEM 身份 + 最高权限）。触发时机不再死等固定秒数：开机 20 秒、登录 10 秒，以及 Windows 判定「网络已连接」时（NetworkProfile 事件 10000，延迟 5 秒）立刻兜一次，登录后每 15 分钟再复查。它只做一件事：如果网卡 DNS 仍指向 127.0.0.1、而 127.0.0.1 上没有 DNS 应答（说明核心异常退出或重启后没起来），就按 dns_backup.json 还原原 DNS。核心正常应答时它什么都不做，所以重复触发无害，正常退出也不必注销任务。注册需要管理员权限。
